Para que serviriam os dados?

Na proposta do Conecta Cidadão, um acesso único reuniria os serviços do município. Informações do perfil ajudariam a identificar o acesso; a escolha de município definiria o contexto dos serviços; e os dados de uma ocorrência ajudariam a descrever um problema.

Compartilhe apenas os dados necessários para utilizar cada serviço. Nunca compartilhe sua senha.
